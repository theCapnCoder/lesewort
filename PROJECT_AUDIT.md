## 1. Общий обзор и Стек технологий

### 1.1 Назначение приложения
**Lesewort** — мобильное Android-приложение для интеллектуального чтения литературы и субтитров на иностранных языках (немецкий `de`, английский `en`, французский `fr`) с глубокой лингвистической интеграцией:
- **Анализ книг:** Автоматический расчет лексической сложности, процента понятности, общего и уникального объема слов.
- **Двухуровневая система баз данных и учета слов:**
  - **Основная база чтения (`known_words`):**
    - `Новое` (незнакомое, стандартный цвет текста книги).
    - `На изучении` (статус `1`, цвет: настраиваемый, по умолчанию **оранжевый / Orange** `#FFA000` / `#E65100`).
    - `Выучено` (статус `2`, цвет: **зеленый / Green** `#10B981` / `#4CAF50`).
  - **Отдельная база данных для игры «Найди пару» (`study_words`):**
    - `«Желаемое»` — слова, добавленные пользователем для отработки в игре «Найди пару».
    - Добавляются кнопкой `+` при чтении или через специальный режим «Добавление незнакомых слов в игру «Найди пару»».
    - В тексте книги выделяются строго **фиолетовым цветом** (`#BA68C8` / `#9333EA`).
    - В «Генерации рассказа» блок словарного запаса содержит фиолетовый блок «Желаемое» (слова из `study_words`).
    - Цвета основной базы (зеленый/оранжевый) и базы «Желаемое» (фиолетовый) строго разделены и не пересекаются.
- **Контекстный перевод и ИИ:** Инлайн-перевод параграфов и всплывающий разбор слов/предложений через LLM (Groq API, OpenAI-совместимый интерфейс).
- **ИИ-генератор историй:** Полноценное написание адаптированных многоглавных повестей по уровням CEFR (A1–C2) с внедрением персонального словаря пользователя (Google Gemini API / Groq).
- **Импорт и поддержка форматов:** Поддержка EPUB (с извлечением глав и обложек), SRT, VTT, TXT, а также системных Intent-фильтров из других приложений.
- **Тренажер слов:** Мини-игра Match Game (парные карточки) и журнал активности/статистики по дням, месяцам и годам.

### 2.2 Навигационная карта и Точки входа

- **Главная точка входа:** `MainActivity.kt` (`onCreate`)
  - Инициализирует базу данных, репозиторий и `MainViewModel`.
  - Устанавливает портретную ориентацию `SCREEN_ORIENTATION_PORTRAIT`.
  - Загружает настройки из `SharedPreferences` (`lesewort_prefs`).
  - При первом запуске инсталлирует стартовую книгу на немецком языке.
  - Обрабатывает входящие `Intent.ACTION_VIEW` / `ACTION_EDIT` для файлов `.epub`, `.srt`, `.vtt`, `.txt`.
- **Нижняя панель навигации (`ScreenTab`):**
  1. `LIBRARY` (`Библиотека`): Список книг с обложками, индикаторами прочитанности, фильтрами по языкам и сортировкой по сложности.
  2. `READER` (`Читалка`): Полноэкранный режим чтения выбранной книги. Нижний бар скрывается для максимального погружения.
  3. `DICTIONARY` (`Словарь`):
     - Вкладка **Словарь**: Список слов с поиском, фильтром (`Все`, `Желаемое`, `Выученные`), удалением и сменой статуса.
     - Вкладка **Статистика**: Календарный лог активности (`WordStatsView`).
     - Вкладка **Тренажер**: Мини-игра Match Game на закрепление слов.
     - Кнопка **«Генерация рассказа»**: Открывает полноэкранный конструктор `GenerateStoryScreen`.
  4. `SETTINGS` (`Настройки`): Выбор языка интерфейса, темы, размера шрифта, цветов подсветки слов и кастомных API-ключей.
- **Фоновые оверлеи:**
  - Плавающий статус-бар генерации рассказа (показывает прогресс написания ИИ, пока пользователь находится на других вкладках).
  - Баннер завершения генерации («Рассказ готов! Читать»).

## 3. Схема Архитектуры и Потоки данных (Data Flow)

### 3.1 Архитектурный паттерн (UDF / MVVM)

```text
┌────────────────────────────────────────────────────────┐
│                     UI LAYER                          │
│  (Compose Screens: Reader, Library, Dictionary, etc.)  │
└───────────────────────┬────────▲───────────────────────┘
          Events / User │        │ StateFlow / UiState
             Actions    ▼        │ (recomposition)
┌────────────────────────────────┴───────────────────────┐
│                    VIEWMODEL LAYER                     │
│                    (MainViewModel)                     │
└───────────────────────┬────────▲───────────────────────┘
               suspend  │        │ Flow<List<T>>
              Functions ▼        │ Coroutines IO
┌────────────────────────────────┴───────────────────────┐
│                   REPOSITORY LAYER                     │
│                   (BookRepository)                     │
└──────────────┬──────────────────────────┬──────────────┘
               ▼                          ▼
┌──────────────────────────────┐   ┌──────────────────────────────┐
│       ROOM SQLite DB         │   │       REMOTE LLM APIs        │
│  - KnownWordDao              │   │  - GeminiStoryService (REST) │
│  - BookDao / ChapterDao      │   │  - GroqAPI (REST)            │
│  - StudyWordDao              │   └──────────────────────────────┘
│  - WordActivityDao           │
└──────────────────────────────┘
```

### 3.2 Сущности данных (Data Entities)

1. **`KnownWord` (`known_words`):**
   - Уникальный ключ: `[word, language]`.
   - `status = 1`: **«На изучении»** (Orange по умолчанию / настраиваемый в Settings) — слова, отмеченные пользователем для изучения в процессе чтения.
   - `status = 2`: **«Выучено»** (Green) — слова, отмеченные как известные.
2. **`BookEntity` (`books`):**
   - Хранит метаданные книги: название, автор, язык, путь к файлу, количество глав/страниц, статистика (процент понятности, лексическая плотность, новые слова).
3. **`ChapterEntity` (`chapters`):**
   - Глава книги, привязанная к `bookId`. Содержит заголовок и сырой текст контента.
4. **`StudyWord` (`study_words`):**
   - Отдельная база данных **«Желаемое»** для игры Match Game («Найди пару»). Содержит слово, перевод, счетчик правильных ответов `correct_count`.
   - Добавляются через кнопку `+` в ридере или режим «Добавление незнакомых слов в игру «Найди пару»».
5. **`WordActivityEvent` (`word_activity_events`):**
   - Журнал событий по времени: когда какое слово получило статус 1 или 2 (для построения графиков и истории).

### 3.3 Жизненный цикл чтения и подсветки слов в Читателе (`ReaderScreen`)

1. Пользователь открывает книгу -> `MainViewModel.selectBook(bookId)`.
2. Загружаются главы книги, словарь `known_words` и словарь `study_words` («Желаемое») для языка книги.
3. Текст главы токенизируется через `LinguisticEngine.tokenizeWord(raw)`.
4. Для каждого слова формируется `SpanStyle`:
   - Если слово в `known_words` со статусом `2` -> **Зеленый** (`ThemeSettings.getLearnedHighlightColor`).
   - Если слово в `known_words` со статусом `1` -> **Оранжевый** (`ThemeSettings.getLearningHighlightColor(learningColorCode)`).
   - Если слово в `study_words` («Желаемое») -> **Фиолетовый** (`Color(0xFFBA68C8)`).
   - Иначе -> Стандартный цвет текста книги (новое слово).
5. При тапе по слову открывается модальное окно разбора:
   - Автоматический запрос перевода через Groq API.
   - Озвучка через TTS.
   - Кнопки трех статусов основной базы: `Новое` -> `На изучении` -> `Выучено`.
   - Кнопка `+` (в фиолетовом стиле): Добавление слова в «Желаемое» («Найди пару»).

## 4. Правила и Соглашения (Conventions)

### 4.1 Дизайн и Цветовая спецификация
- **База «Желаемое» («Найди пару» / `study_words`):** Всегда строго **фиолетовая гамма**:
  - Цвет текста / бейджа / кнопок: `Color(0xFF9333EA)` / `Color(0xFFBA68C8)`.
  - Фон контейнеров: `Color(0xFF9333EA).copy(alpha = 0.12f..0.15f)`.
  - Обводка (Border): `Color(0xFF9333EA).copy(alpha = 0.35f)`.
- **Статус «На изучении» (`known_words`):** По умолчанию **оранжевая гамма**:
  - Цвет текста / бейджа: `Color(0xFFE65100)`, подсветка: `Color(0xFFFF9100)` (настраивается пользователем в Настройках: оранжевый, синий, желтый, фиолетовый).
- **Статус «Выучено» (`known_words`):** Всегда **зеленая гамма** (`Color(0xFF10B981)` / `Color(0xFF059669)` / `Color(0xFF2E7D32)`).
- **Разделение баз:** Цвета базы «Найди пару» («Желаемое», фиолетовый) и основной базы чтения («На изучении», оранжевый) строго изолированы и не пересекаются.
- **Общие токены M3:** Для поверхностей и фона используется `MaterialTheme.colorScheme`. Кастомные цвета применяются только для семантической разметки статусов слов.

### 4.2 Соглашения по коду (Code Style & Best Practices)
1. **Язык и реактивность:** Только Kotlin + Coroutines Flow. Избегать блокировок потока UI (`Dispatchers.IO` для БД и парсинга).
2. **Идентификация элементов (TestTags):** Каждый кликабельный элемент и поле ввода **обязаны** содержать `Modifier.testTag("snake_case_id")` (например, `story_generator_back_button`, `radio_study_words_toggle`).
3. **Строковые ресурсы:** Пользовательский интерфейс и подсказки локализованы на русском языке.
4. **Конфиденциальность и ключи:** Ключи Gemini берутся через `BuildConfig.GEMINI_API_KEY` (настраиваются в Secrets AI Studio или `.env`). Пользовательские ключи Groq хранятся локально в `SharedPreferences`.

### 4.3 Ограничения и Запреты (Strict Constraints)
- **ЗАПРЕЩЕНО** изменять имя проекта в `metadata.json` в отрыве от `strings.xml`.
- **ЗАПРЕЩЕНО** удалять `MAJOR_CAPABILITY_SERVER_SIDE_GEMINI_API` из `metadata.json`.
- **ЗАПРЕЩЕНО** модифицировать или заменять `debug.keystore` и `signingConfigs`.
- **ЗАПРЕЩЕНО** создавать или запрашивать файл `local.properties`.
- **ЗАПРЕЩЕНО** использовать моковые/фейковые данные для функционала, запрашивающего реальные книги или перевод.
